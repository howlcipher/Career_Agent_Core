## Findings from the pre-flight code map

1. **There is no single submit chokepoint.** Six real `.Click()` submit sites in `pkg/submitter/browser.go`, each individually guarded by `if autoSubmitClick`: `handleDynamic` :3701, `handleGreenhouse` :1976, `handleLever` :2042, `handleAshby` :1884, the validation-retry resubmit :1687, and the post-security-code resubmit :1541.
2. **BUG (new, filed as bugs.md #432): `auto_submit_click: false` writes a false `APPLIED`.** Every handler fills the form and returns `nil` without clicking, and `confirmOrError` (browser.go:520) short-circuits `return nil` at :521. `cmd/agent/pipeline.go:490` reads `err == nil` as success and writes `status = APPLIED` plus a dedup row in `applied_jobs` — for a form that was never submitted. Same defect class as bugs #94/#95 (pipeline misreading its own outcome). Copilot Mode cannot reuse this return path, so the fix ships with this item.
3. **`ReapStaleProcessingJobs`** (manager.go:1019, called from cmd/agent/main.go:797) resets `PROCESSING → DISCOVERED` on restart, so a review-pending job needs its own status, and that status needs a rank in `mergeStatuses` (manager.go:258) or dedup merges silently discard it.
4. **Dashboard and agent share only `applications.db`** — no IPC. A review signal must be DB- or file-based.
5. `headless_browser` is a process-wide launch decision (cmd/agent/main.go:818); `AttemptSubmit`'s `headlessBrowser` parameter is accepted and never used.

## Design (scoped to Effort 2, matching the row's score)

Copilot Mode = *fill everything, stop before the irreversible click, hand the human a ready-to-finish application.*

- `copilot_mode: bool` on `config.Profile`.
- New sentinel `submitter.ErrAwaitingHumanReview`; a single `submitGate(copilotMode, autoSubmitClick)` helper consulted at all six click sites so the gate cannot drift between fill paths (the recurring #65/#66→#67, #74→#75, #28→#31 pattern).
- New sentinel `submitter.ErrSubmitClickDisabled` for the plain `auto_submit_click: false` case — closes finding 2.
- `cmd/agent/pipeline.go` branches both sentinels before its generic-error arm: `AWAITING_REVIEW` status, docs moved to the manual-apply dir, and a row appended to `applications/needs_manual_apply/copilot_queue.md` with the apply URL and the generated document paths.
- `AWAITING_REVIEW` ranked in `mergeStatuses`, labeled in the dashboard's `statusReason`, and counted in `/api/metrics`.
