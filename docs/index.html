The Evolution

Next-generation capabilities powered by Go 1.26, pushing the boundaries of autonomous application.

Visual Reasoning (VLM)

Leverages native multimodal AI to visually "see" the page. When DOM extraction fails due to heavy obfuscation, the agent snaps a screenshot and uses spatial intelligence to pinpoint elements.

IMAP Tracker Daemon

Silently monitors your inbox in the background, reading rejection and interview emails to automatically update your job funnel database.

Go 1.26 Native

Built exclusively on Go 1.26.5+, utilizing the latest runtime optimizations for parallel scraping, rapid model context building, and zero-allocation networking.

Live Web Dashboard

A zero-dependency embedded web server showing live funnel counts, active conversions, and the status of current applications in real-time.

Cron-Driven Drip

Run the engine with --daemon to let it seamlessly drip 10-15 tailored applications every 6 hours, completely evading ATS rate limit bans.

Local-First, Multi-Provider AI

Runs entirely on your machine with Ollama by default — zero API cost, zero data leaving your box. Seamlessly integrates with Claude or Gemini for flexible reasoning. Uses SQLite WAL mode for highly concurrent, safe tracking.

Core Architecture

Engineered for absolute stealth, resilience, and efficiency.

  • Self-Healing DOM Mapping Invalidates stale Playwright CSS selectors if a website updates its UI, forcing a localized structural re-learn.
  • Dynamic Learner Module Autonomously parses unknown ATS layouts (like Workday), maps selectors dynamically via LLM, and caches the blueprint.
  • Resolver-Bound Outbound Networking Strict net/url IP-binding algorithm automatically prevents DNS rebinding attacks and validates public IP endpoints.
  • Strict Promptsec Quarantine Secure text-parsing layer neutralizes malicious indirect prompt injections embedded in external job descriptions.
  • Stealth Writer Bypasses AI detection algorithms with humanizing delays, active voice enforcement, and zero corporate buzzwords.
