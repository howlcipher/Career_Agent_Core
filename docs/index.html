System modules

Purpose-built components for repeatable, local, and reviewable application work.

Visual form recovery

Leverages native multimodal AI to visually "see" the page. When DOM extraction fails due to heavy obfuscation, the agent snaps a screenshot and uses spatial intelligence to pinpoint elements.

Inbox outcome tracker

Silently monitors your inbox in the background, reading rejection and interview emails to automatically update your job funnel database.

Go-native runtime

Built on a 100% CGO-free stack using Go 1.26.5+, utilizing modernc.org/sqlite, parallel scraping, and rapid model context building.

Local operations console

A zero-dependency embedded web server showing live funnel counts, conversion rates by ATS platform and by cover-letter variant, and the status of current applications in real-time, complete with start/stop agent controls. It binds to loopback only, and the start/stop endpoints reject any request that is not same-origin, so no other page open in your browser can launch a run on your behalf.

Bounded queue cycles

Run the engine with --daemon to let it seamlessly process up to 15 jobs every 6 hours, completely evading ATS rate limit bans.

Human-controlled handoffs

Does every expensive step — scoring, tailoring, and proving the form is live and fillable — then stops before the final click. Vetted roles land in a review queue with their tailored documents, ready for you to submit yourself where bot protection blocks a bot but not a person.

Local-first model routing

Runs entirely on your machine with Ollama by default — zero API cost, zero data leaving your box. Seamlessly integrates with Claude or Gemini for flexible reasoning. Every document is written in-process by whichever provider you configured, with no companion service to install; an optional FastAPI offload exists for anyone who wants generation running outside the agent. Uses SQLite WAL mode for highly concurrent, safe tracking.

Engineering principles

Bounded automation, explicit outcomes, and layered safeguards.

  • Self-Healing DOM Mapping Invalidates stale Playwright CSS selectors if a website updates its UI, forcing a localized structural re-learn.
  • Dynamic Learner Module Maps unknown ATS layouts such as Workday through a bounded LLM-assisted workflow, then caches the reviewed blueprint.
  • Resolver-Bound Outbound Networking Strict net/url IP-binding algorithm automatically prevents DNS rebinding attacks and validates public IP endpoints.
  • Deterministic Prompt-Injection Quarantine Secure text-parsing layer neutralizes malicious indirect prompt injections embedded in external job descriptions, with a conservative allowlist for legitimate ATS boilerplate so real postings aren't discarded alongside real attacks.
  • Document Quality Guardrails Produces tailored, readable documents with explicit review boundaries and without pretending to bypass employer controls.
  • Stateful Graph Pipeline Processes complex multi-step application forms using a robust, state-machine driven graph architecture.
  • Concurrent Processing Pipeline Splits monolithic generation into concurrent processes, and utilizes bounded worker pools and parallel IO streams for high-speed scraping and inference.
